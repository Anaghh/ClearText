ClearText 0.3.0 - Native Windows text reader and editor

Extract the ZIP and double-click ClearText.exe.
Requires Windows x64 with .NET Framework 4.8. No Python is required.

Press F1 for the side-by-side tutorial, or read TUTORIAL.md.
Use Practice space to try the app without changing an existing file.

Ctrl+N new, Ctrl+O open, Ctrl+S save, Ctrl+Shift+S save as,
Ctrl+F find, Ctrl+G go to line, Ctrl+W close tab. Escape closes search.

Features: tabs, light/dark theme, text sizing, word wrap, optional line numbers,
read-only mode, inline search, native dialogs, and external-change save checks.

Reading tools: Focus lens, inferred heading map, Ctrl+B bookmarks, reading time,
and saved reading positions for unchanged files. Cycle Sans / Book / Code fonts.
Preferences are stored locally under %LOCALAPPDATA%/ClearText/preferences.xml.

Preview limits: 20 MB per file. No automatic tab restore or crash recovery yet.
Mixed line endings are normalized to the detected style on save.
The EXE is unsigned. See THIRD_PARTY_NOTICES.md and LICENSE.
